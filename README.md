# Iris Flower Classification using KNN

## Project Overview

This project implements a Machine Learning classification model using the famous Iris Flower Dataset. The objective is to classify iris flowers into different species based on their measurements.

The model uses the K-Nearest Neighbors (KNN) algorithm, a supervised learning technique that classifies data based on similarity with neighboring data points.

---

## Features

* Loads the Iris Dataset
* Splits data into training and testing sets
* Applies feature scaling using StandardScaler
* Trains a KNN classifier
* Predicts flower species
* Evaluates model performance using accuracy score
